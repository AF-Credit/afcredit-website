Accessibility Statement

We want everyone to be able to use this website — here's what we do, and how to tell us when something isn't working.

Last updated: 21 July 2026

Our commitment

This website is run by AF Credit, a trading style of Chammosair Limited. We want as many people as possible to be able to use it, and we aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 level AA wherever practical.

What we've done

  • Semantic HTML structure with proper heading hierarchy, labelled forms and descriptive link text
  • Text alternatives on informative images
  • Keyboard-operable navigation, including a mobile menu with ARIA state attributes
  • Readable font sizes and a colour palette chosen for contrast against its backgrounds
  • Responsive layout that supports zoom up to 400% and works across screen sizes
  • Breadcrumb navigation with ARIA labels on every page

Known limitations

Some interactive elements — such as the bridging loan calculator and FAQ accordions — rely on JavaScript. All essential information (rates, criteria, contact details) is available as plain text without JavaScript. Some older case study images may have brief rather than fully descriptive alternative text; we improve these as pages are updated.

If something isn't working for you

If you have difficulty using any part of this website, or need information in a different format — large print, plain text by email, or explained over the phone — contact us and we will help promptly:

  • Email: enquiries@afcredit.co.uk
  • Phone: 01451 514 563 (Mon–Fri 8am–7pm, Sat 9am–2pm)

We take accessibility feedback seriously and use it to prioritise improvements to the site.
